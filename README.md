A short passage written to make the AI judge feel curious, for make.fun's
`make-the-ai-judge-feel-curious-20261122-2311` bounty. A key waits in a drawer
for a lock that was never made — and wonders, as the reader does, what it
might open.

## How to run

```sh
python3 main.py
```

This writes the text to `MAKEFUN_OUTPUT_DIR/entry.txt` (or `./output/entry.txt`
if the variable is unset), then reads it back and verifies it is 1–280
Unicode code points and not whitespace-only. Python 3.13 standard library
only; no network.
